# Architecture Decision Records

Format: `NNNN-short-title.md`, containing Status, Context, Decision, Consequences, Alternatives rejected and Verification. Each ADR is subordinate to `SPEC.md`. An ADR that would change SPEC architecture must be paired with an explicit SPEC.md amendment.

Number ranges are reserved per subsystem group; see `plans/00-master-plan.md` §3. ADRs 0001–0099 are global decisions made by the Stage-0 lead planner.
