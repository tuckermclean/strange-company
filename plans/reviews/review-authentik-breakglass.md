## 2. Verdict

**FAIL** as written. It moves to **PASS WITH FIXES** once AUTH-1 is resolved and the majors below are addressed.

Most of the architecture is sound and better than typical:
- Authentik is PostgreSQL-only and configured from Git blueprints.
- `user_uuid` subjects mean OIDC links survive a restore.
- The bootstrap credential is single-use, and its teardown is verified.
- Cluster admin uses SSH plus the node-local kubeconfig, with no long-lived offline client certificate.
- Break-glass use is detected from timestamps kept by the source system.
- The drill is quarterly and records evidence.
- The TLS design uses a DNS-01 wildcard in both ingress modes and an internal CA held in Git (SOPS).
- In-cluster OIDC goes through the CoreDNS rewrite.

The defects are in the details that decide whether the controls actually hold:
- Upstream Authentik flows are left unguarded, so MFA can be bypassed and the empty-database takeover window is open.
- Break-glass audit for cluster admin cannot tell break-glass use from routine use.
- Any of several in-cluster actors can silence break-glass alerts.
- Restoring a corrupted Authentik requires a Git merge, and the human merge path depends on Authentik.
- The Cloudflare-down path assumes DNS control that Cloudflare itself holds.
- Several GATE-P07 acceptance criteria depend on components that are only delivered at P09 or C08.
