# SPEC issues register

**Purpose:** SPEC §0 requires that contradictory, impossible, unsafe, falsely assumed, or disproportionately expensive requirements be surfaced explicitly, never silently reinterpreted. This register records every such finding from Stage 0, its classification and its resolution.

**Classification**
- **Contradiction:** two SPEC statements cannot both hold.
- **False assumption:** SPEC assumes a fact that is not true or not verified.
- **Underspecified:** SPEC leaves a decision open. A conservative resolution is recorded.
- **Interpretation:** SPEC wording admits more than one reading. The chosen reading is recorded.
- **Cost/risk:** the requirement is achievable but disproportionately expensive or risky as literally stated.

**Blocking?** "Yes" means implementation of the affected DAG nodes may not start until the item is resolved, by a SPEC amendment or an operator decision.
